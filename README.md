# CS2 Bhop
### Requirements: Visual Studio 2022 community, CS2
### How to build:
First download VS 2022 community if you haven't already and when installing select Desktop development with C++. \
Then run the dumper I provided to get the newest CS2 offsets. \
And now you can just run build.bat script to compile this tool.  \
If you want you can run the game first then hit build.bat now I added calls to the dumper so build.bat dumps offsets and compiles the tool.
